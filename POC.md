# Whole-requirement enforcement PoC

This branch is an experimental Agent Sessions integration, not a production
release or an upstream-ready proposal. Use the matching Sessions Substrate
variant, not the kagent variant.

The [complete PoC guide](https://github.com/vfalico/agentsuite-guardd/tree/poc/whole-requirement-v1/docs/poc)
provides exact source pins, the dependency graph, setup, build and test commands,
demonstrated results and limitations. Canonical module/import paths are unchanged.
